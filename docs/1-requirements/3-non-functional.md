# ⚙️ Requisitos Não Funcionais

> Derivados das Histórias de Usuário HU-01 e HU-02.

Os requisitos não funcionais descrevem **como o sistema deve se comportar**.

| ID    | Categoria        | Descrição                                                                                   |
| ----- | ---------------- | ------------------------------------------------------------------------------------------- |
| RNF01 | Usabilidade      | O fluxo de pedido deve ser completado em no máximo 5 interações (uma por categoria + confirmar) |
| RNF02 | Usabilidade      | O feedback visual deve ser imediato após cada seleção (placeholder substituído na tela)      |
| RNF03 | Compatibilidade  | O app deve funcionar em dispositivos Android com API Level 21 (Android 5.0) ou superior     |
| RNF04 | Distribuição     | O app é distribuído como arquivo `.apk` e não requer publicação em loja oficial              |
| RNF05 | Desempenho       | A navegação entre telas deve ser fluida, sem atrasos perceptíveis                           |
| RNF06 | Manutenibilidade | O app deve ser editável pela plataforma Kodular sem necessidade de IDE ou código nativo     |
