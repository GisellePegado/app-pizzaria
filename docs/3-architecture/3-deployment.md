# 🚀 Instalação e Distribuição

## 📋 Requisitos de ambiente

| Dependência  | Versão mínima              | Observação                             |
| ------------ | -------------------------- | -------------------------------------- |
| Android OS   | 5.0 (API Level 21)         | Versões anteriores não suportadas      |
| Armazenamento| ~5 MB livres               | Para instalação do APK                 |
| Permissão    | Fontes desconhecidas ativas | Necessária para instalar APK externo   |

> [!IMPORTANT]
> Antes de instalar, ative a permissão de **"Instalar apps de fontes desconhecidas"**
> nas configurações do seu dispositivo Android.
> Em Android 8+, essa permissão é solicitada por app (geralmente o gerenciador de arquivos
> ou o navegador usado para baixar o APK).

---

## 📦 Versões disponíveis

| Arquivo                   | Versão | O que inclui                                              |
| ------------------------- | ------ | --------------------------------------------------------- |
| `SotfwarePizzaria.apk`    | v1     | Tela principal + seleção de sabor salgado                 |
| `SotfwarePizzaria_v2.apk` | v2     | + Seleção de sabor doce                                   |
| `SotfwarePizzaria_v3.apk` | v3     | + Seleção de borda e bebida                               |
| `SotfwarePizzaria_v4.apk` | v4     | + Tela de confirmação com resumo completo do pedido ✅    |

> [!TIP]
> Instale sempre a versão mais recente (`v4`) para ter acesso ao fluxo completo.

---

## 💻 Como instalar

1. Acesse o repositório no GitHub pelo celular ou transfira o arquivo `.apk` para o dispositivo
2. Localize o arquivo `SotfwarePizzaria_v4.apk` no gerenciador de arquivos
3. Toque no arquivo e confirme a instalação
4. Após instalado, o app aparecerá como **"PedePizza1.0"** na gaveta de apps

## 🛠️ Como editar o projeto

O projeto foi construído no **Kodular Creator** — plataforma visual online.

1. Acesse [kodular.io](https://www.kodular.io)
2. Faça login e importe o arquivo de projeto (`.aia`) se disponível
3. Edite telas, componentes e blocos de lógica visualmente
4. Compile e exporte um novo APK diretamente pela plataforma
